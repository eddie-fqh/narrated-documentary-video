# 找素材：候选池、目检、授权

目标：一期 9 分钟的片子用到 70 个以上不同素材，其中视频 10 段以上。素材少，画面就会循环往复。

## 1. 去哪找

| 类型 | 来源 | 授权与备注 |
|---|---|---|
| 作品、文物、老照片、版画、地图 | Wikimedia Commons | 只收公有领域、CC0、CC BY、CC BY-SA（`scripts/commons.py` 已按此过滤） |
| 博物馆藏品高清图 | 各大博物馆的开放获取接口（大都会、芝加哥艺术博物馆、克利夫兰、荷兰国立博物馆、史密森尼、Europeana、法国国家图书馆 Gallica） | 多为公有领域或 CC0；部分接口要免费申请 key |
| 老影像、公有领域音乐 | Internet Archive | 逐条看授权 |
| 高清实景照片 | Unsplash、Pixabay、Pexels | 免费可用；记作者 |
| 实景视频 | Pixabay、Pexels | 只要横屏 1080p 那一档 |
| 环境声 | Freesound | 逐条看授权（CC0 / CC BY / CC BY-NC） |
| 老地图 | 大型地图收藏的数字馆藏 | 常见 CC BY-NC-SA，只能用于非商业频道 |
| 三维扫描模型 | Sketchfab、Scan the World（MyMiniFactory） | 见第 5 节 |
| 航拍、地形 | Google Earth Studio、开放地图瓦片 | 见 aerial-and-maps.md |

社交平台上别人的图片、视频只用来找点子，不下载、不使用。

## 2. 候选池工作流

不要「搜到第一张就用」。先建候选池，看样张再挑。

```bash
python3 scripts/pool.py search <ep> "Fountain of X river god statue detail" "architect portrait engraving" …
python3 scripts/pool.py sheet <ep>            # 生成带编号的样张 pool/sheet_000.png …（每张 30 格）
# 打开样张看。每格有 #编号、检索词、文件名
python3 scripts/pool.py pick <ep> 12:fountain_detail 40:architect_portrait     # 编号:本地 key → 下载到 img/，写 credits.json
python3 scripts/pool.py sheetimg <ep>         # 已下载图片的样张，核对错图
```

- 检索词用英文，具体到对象和局部。稿子里每个讲到的具体东西都要有检索词（写稿时的 `queries.json`）。
- 搜不到就逐步缩短检索词，或换成对象的原文名。
- 接口返回 429 就退避等待；连续 429 说明请求太密，停下来，不要并发硬顶。
- 设 `COMMONS_UA` 为带项目地址或联系方式的 User-Agent（Wikimedia 的要求）。
- 小于 2000 像素宽的老图推近时会糊：设 `UPSCALE_MIN_WIDTH=2000`，下载时用 Real-ESRGAN 放大到 2560 宽（`scripts/upscale.py`；照片和油画用默认模型，线刻版画用 `--anime` 线条更干净但会抹掉纸纹）。

库存视频下载后先确认能完整解码（`ffmpeg -v error -i x.mp4 -f null -` 无输出），竖屏的剔掉，4K 的压到 1080p 再用。

## 3. 目检：错图是最严重的错误

每张图在用之前都要看过，并回答「这是不是口播说的那个东西」。实际踩过的错：

- **同名不同物**：同名的建筑、同名的广场在别的城市。看图的来源页描述，不只看文件名。
- **同类不同个**：航拍片段拍的是隔壁那座建筑；库存视频标题写的是城市名，画面是另一处地标。
- **人物张冠李戴**：父子、师徒、同姓的两个人；画像下面的人名牌必须是这个人。
- **年代不对**：讲 16 世纪的工地，用了 18 世纪的版画。
- **朝向和口播矛盾**：说「往下看」给了仰拍，说「正面」给了背面。
- **铭文、局部**：标注圈要落在真正的那几个字上；找不准就改用聚焦框，或者换图。
- 带水印的图、以清晰路人正脸为主体的照片、主体被裁掉头的图，不用。

看过确认不对的图移到 `<ep>/rejected/`，下载脚本不会再把它拉回来。错图的文件名记进项目级的黑名单，免得下一期又用上。

## 4. 授权与署名

- `credits.json` 每个素材一条：来源页、作者、授权。片尾或视频描述按授权要求署名。
- **按源头的授权写。** 转传平台上的标签可能被上传者改过。
- 带「非商业」（NC）限制的素材只在频道确实非商业时使用，并照样署名；SA 的按相同方式共享。频道一旦开始变现或接商单，已经用过的 NC 素材要重新过一遍。
- 地图瓦片、卫星底图、航拍都要求署名一直留在画面上，不裁、不遮。

## 5. 三维模型

- 先查有没有**真扫描**。平台上「可下载 + CC BY」的雕塑模型，去源头再查一遍：多个账号上传同一个网格、三角面数完全相同，就是转传的，授权以最早的发布者为准。
- 开源扫描库里的条目不一定是扫描，有的是照着原作重塑的（评论区常有人指出）。重塑模型只用来做整体、路线、环绕；细节一律用实拍照片。在 `factcheck.md` 里写明「不是扫描」。
- 模型处理：合并、焊接、简化、压缩贴图到 2048；按测绘尺寸缩放到真实大小；朝向用点云的最小外接矩形定。
- 找不到合适的模型就程序化建模（animation.md）。

## 6. AI 生成的画面

- 只做气氛镜头和明确标注的「复原示意」（云、光、水、故事场景连环画）。**不用它冒充具体对象的实拍。**
- 画面上或描述里标明「AI 生成」；多数平台要求发布时主动声明。
- 付费生成要有费用闸门：默认空跑只打印预估费用；真实调用必须同时带 `--yes` 和 `--max-cost`，预估超过上限就不发请求；价格表里没有的模型或分辨率组合一律拒绝；任务一提交就记下任务号，下载失败用任务号续取而不是重新生成。
- 生成之前问用户。价格和模型换得很快，用之前现查，不要凭记忆。

## 7. 参考视频

想知道同题材的好片子怎么拍，在平台上在线观看并记分镜笔记（做法见 animation.md 末尾）。不下载别人的视频，更不拿来当素材。

## 8. 素材到齐才渲染

渲染器找不到素材时会「沿用上一镜头」并在日志里写一行警告——成片不会报错，但那一镜就是错的。渲染前确认镜头表里的每个文件都在；渲染后看日志里的回退次数，不为零就补齐重渲。
