# 合成：画面、字幕、配乐、环境声

```bash
bash scripts/glock.sh render 2 bash scripts/render_ep.sh <ep>
```

`render_ep.sh` 依次做：`render.py`（镜头表 → 无声画面）→ `finish.py`（字幕 + 配乐 + 环境声 + 响度，烧字幕出成片）→ 原子替换 `final.mp4` → 逐镜截帧样张。单期 9 分钟的片子约 8–15 分钟。

## 1. 画面（`render.py`）

- 每个镜头的起止先量化到整帧，避免恒定帧率下的累计漂移。
- 实拍素材统一过一层调色：略暖、暗角、细颗粒，让来源各异的图看起来是一部片子；动画片段不调色（它自带底色）。
- 中间片在 macOS 上用硬件编码（快约 4.5 倍），成片统一用 x264 重编。
- 只渲一段做样片：`render.py shots.json out.mp4 --from 60 --to 90`。
- 镜头时间写进 `work/shot_times.json`，QA 样张和排查都用它。
- **素材找不到时沿用上一镜头**并写一行警告。渲染完看 `work/log_render.txt` 里的回退次数。

`render_ep.sh` 渲染完会删掉中间的无声画面——所以即使只改了配乐或字幕，也要整期重渲。

## 2. 字幕（`finish.py`）

字幕时间直接取逐字对齐的结果：每条字幕从它第一个字的发音时刻前 0.08 秒出现，停到下一条之前。

断行：

- 在「，。」处断；问号、叹号、分号后也断（保留标点）。
- 超过 18 字的行在中点附近切成两条，**优先切在词边界**（jieba 分词），不把一个词拆到两行；本期人名牌、地名牌、作品牌里的专名会先加进词典，长音译名不被拆开。
- 不在英文单词中间切；不紧跟在数字后面切；间隔号「·」前后 3 个字内不切。
- 只有一个字的行并入下一行（单字答句「有。」并入时留一个空格）。

数字显示（稿子里是汉字，字幕显示阿拉伯数字）——坑很多，规则都在 `disp()` 里：

- 四位逐字读的年份 → 数字；年份区间两头一起转。
- 带「十百千万」的数目 + 单位 → 数字；区间两头一起转。
- 裸的「百、千、万」（「上万件」）不是数字，原样保留。
- 约数（「五六十」「十七八岁」）保持中文。
- 人名里的「十世」「十三世」保持中文；「世纪」照转；并列世纪（十七十八世纪）拆成「17、18世纪」。
- 钟点的时和分一起转；「分之」不转。
- 整万数显示成「1000万」而不是一长串零。

**字幕上下跳 = 相邻两条时间重叠**（后一条被顶到上一行）。流程是：先统一提前开始时间，再按「已调整的」下一条开始时间截断结尾；写文件时按厘秒整数再校一遍。改字幕逻辑后务必保留这两道。

拉丁字体没有中文字形，中西混排的地方（年份里的「前」、外文名里夹的中文）要逐字选字体，否则显示成方框。

## 3. 配乐

`music.json`：`[["__start__", "曲名", 1.0], ["第一章开头的原文", "曲名", 1.0], …]`，曲子在 `project/music/<曲名>.mp3`。

- 按章节换曲。钩子、正文各章、实用段、收束，情绪各不相同。
- 每首曲子先各自拉到同一积分响度（−20 LUFS）——不同曲目的响度能差 20 dB，不拉齐的话换曲时忽大忽小。
- 每段 1.5 秒淡入、2.5 秒淡出，段与段重叠 2 秒。
- **人声侧链闪避**：有人说话时配乐自动压低，句间停顿时浮上来。
- 混音后整体归一到 −16 LUFS、真峰值 −1.5 dB。
- 第三列是这一段的音量倍数；偏吵的曲子调到 0.7–0.8。

配乐用公有领域或授权明确的曲目，记进署名清单。

## 4. 环境声

`ambience.json`：`[["起始锚点", "文件.mp3", 素材起点秒, 相对响度dB, 淡入秒, 淡出秒, "结束锚点"], …]`，文件在 `project/assets/sfx/`。

每章一段真实的现场声——广场人声、室内混响、水声、钟声、风。它让静态图片「有空气」。音量压在人声下面 15–20 dB，听得出在场但不抢话。按章节切换，换场时淡出淡入。

## 5. 安全区

| 区域 | 位置（1080p） | 谁占用 |
|---|---|---|
| 字幕带 | 底部约 160 像素 | 字幕；标签、示意图的地面线都要在它上面 |
| 顶部条带 | y 34–166 | 时间线条；有它时地点牌自动下移 |

动画页面里的标注、数字也要遵守字幕带——地面线、图注别落到底部 160 像素里。

## 6. 重渲的规矩

- 不原地写 `final.mp4`：写临时文件，完成后改名替换。别的程序（审片页、上传）不会读到半截文件。
- 同一期同时只跑一个渲染（目录锁）。上一次渲染被打断留下的陈旧锁，确认进程已死后会被接管。
- 改了共用的渲染代码但输入没变时，按输入时间判断「要不要重渲」的守卫会跳过——`touch shots.json` 再渲。
- 长渲染要脱离调用方的进程树（ops.md）。
