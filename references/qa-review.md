# 审片

渲染成功只说明程序跑完了。片子对不对，要靠看和听。

## 1. 逐镜样张（每次渲染后必做）

`render_ep.sh` 结束时生成 `work/qa_sheet_N.png`：每个镜头在 70% 处截一帧，6×8 拼成一张。逐张看：

- **错图**：画面是不是口播此刻说的那个对象（对照 `work/shot_times.json` 里每镜的锚点文字）。
- **标签错位**：人名牌下面是不是这个人；作品牌是不是这件作品；标注圈是不是指在那个细节上；聚焦框框得准不准。
- 人像、雕像的头有没有被裁掉；主体是否完整。
- 黑帧、灰帧、素材回退（和上一镜一模一样的画面）。
- 同一张图是否连续出现或出现超过两次。
- 动画有没有黑边、错字、标签压住模型；对比镜头两侧是否都完整。
- 字幕有没有压住关键内容。

发现问题改镜头表（改生成器脚本，重新走合并和时间线），重渲。

## 2. 自动扫描

```bash
bash scripts/scan_video.sh final.mp4
```

- **静止段**：检测连续多秒完全不动的画面。刻意的定格（比如让观众读一行字）可以保留，但要知道它在哪。
- **黑场**：片头片尾以外不该有。
- **音频**：整体响度、有没有削波、有没有长时间无声。
- 时长：成片时长 ≈ 配音时长 + 片尾留白。

## 3. 独立复核

做片子的人看自己的片子，容易顺着自己的意图看。让一个**没参与制作**的审片者（新开的子代理即可）从头看一遍，只给它成片的截帧和口播稿，不给镜头表和你的结论，让它回答：

- 每个镜头的画面和这句话对得上吗？列出对不上的时间点。
- 有没有地点、人物、年代、朝向明显不符的画面？
- 口播里有没有前后接不上、听着别扭的句子？
- 哪一段最无聊？哪一段画面重复？

它提的每一条都回到原图和出处核实后再改——审片者也会看错。

## 4. 人听一遍

配音里的读错、多音字、别扭的停顿，机器闸门抓不到。成片要有人完整听过。常见反馈和对应处理：

| 反馈 | 处理 |
|---|---|
| 某个字读音不对、同一个词前后读音不一致 | `tts_subs.json` 加替换，重做所有含这个词的段 |
| 某句话听着怪、逻辑接不上 | 改稿，局部重配（voice.md 第 6 节） |
| 某处有杂音 | 窄时间窗衰减 |
| 画面一闪一闪、微微跳 | 多半是动画片段比镜头短被放慢了（animation.md 第 2 节） |
| 阴影一块一块地闪 | 三维场景里有共面的面 |
| 太快看不清 | 多图横移改成分组停留；镜头合并得更长 |
| 这一帧不是在说的那个东西 | 错图：换图，并把错图加进黑名单 |

用户指出一个问题时，把**同类问题在全片和其他期里**都查一遍，不只修他指的那一处。

## 5. 给用户审片

- 成片放到一个只有自己人能访问的审片页（内网或私有网络上的静态页面即可），每期一个播放器加封面，标明版本时间和是否已发布。
- **只上架完整的成片**：以渲染日志的完成标记为准，拷贝用临时文件加原子改名——否则审片页会拿到半截文件。
- 对外的临时隧道链接任何人拿到都能看未发布内容，用完就关。
- 审片服务会无声停掉；把链接发给用户之前先自己请求一下确认它活着。

## 6. 过审标准

一期可以交给用户审的条件：样张逐张看过且没有已知错图；自动扫描无异常（或逐条说明）；素材回退为 0；配音闸门通过且转写核对过数字和专名；`richness.py` 各项达标或说明原因；每个素材有授权记录。

交付时如实说明：哪些核实过、哪些没有（比如「某张图的作者待核」「没做独立复核」）。不要把没做的检查说成做了。
