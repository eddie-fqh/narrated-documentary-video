# 分镜与运镜

## 1. 锚点：镜头跟着话走

每个镜头的 `at` 是口播稿里**原样出现**的一段文字，镜头在这段文字第一个字发音前约 0.12 秒切入。`__start__` 是片头第一镜。

```json
{"tail": 4.5, "shots": [
  {"at": "__start__", "type": "vid", "src": "video/aerial_01.mp4", "fade_in": 1.0},
  {"at": "某句原文", "type": "img", "src": "img/key", "move": "in"},
  {"at": "某句原文", "type": "img", "src": "img/key", "kb": [[1.0, 0.5, 0.5], [1.25, 0.5, 0.35]]},
  {"at": "某句原文", "type": "art", "src": "img/painting"},
  {"at": "某句原文", "type": "focus", "src": "img/key", "rects": [[0.1, 0.2, 0.3, 0.3, "标注"]]},
  {"at": "某句原文", "type": "split", "src": "img/a", "src2": "img/b"},
  {"at": "某句原文", "type": "grid", "items": ["img/a", "img/b", "img/c"]},
  {"at": "某句原文", "type": "vid", "src": "video/clip.mp4", "ss": 10}
]}
```

镜头表不要手写 JSON，写一个生成器脚本（`templates/episode/build_shots.example.py`，工具在 `scripts/shotlib.py`）：动画时长、提示点都从对齐结果里算，改稿重配后重跑一遍就行。

**顺序游标的坑**：渲染器按顺序找锚点，每找到一个就把游标挪到它后面——同一短语在稿里出现两次时，靠顺序区分。生成器里不按顺序取时间时，用 `L.T(短语, after=前面的某句)` 指明是哪一次，否则会报「锚点找不到（或顺序错了）」。

`scripts/clauses.py <ep>` 列出每个短句的开始时间和时长，排镜头时对着它看。

## 2. 镜头类型

| type | 画面 | 用在 |
|---|---|---|
| `img` | 整屏照片 + 缓慢推拉平移 | 实景、建筑、环境 |
| `art` | 虚化底 + 居中完整作品（带投影），不裁切 | 画作、雕塑、文献——需要看全貌的 |
| `focus` | 整幅 → 依次推近几个局部，金框 + 标签 | 「你仔细看」「找一找」 |
| `split` | 左右并排 | 前/后、原作/复制、两种方案、实拍/复原 |
| `grid` | 2–5 张卡片错落入场 | 同类并列、一组人物 |
| `montage` | 几个素材在一个镜头里依次叠化 | 快速带过一组画面 |
| `vid` | 视频片段（`ss` 起点，`speed` 变速）；`anim/` 开头的是专属动画 | 航拍、实景、动画 |

## 3. 运镜

舒缓是底线。观众在听一段需要思考的话，画面不该抢。

- 预设 `move`：`in`（1.02→1.09 慢推）、`out`、`left`、`right`、`up`、`down`、`none`。幅度都在 5%–10%。
- 自定义 `kb: [[缩放, cx, cy], [缩放, cx, cy]]`，起点到终点，带缓入缓出。
- **`cx/cy` 不是中心坐标**，是裁切框在余量里的位置（0 贴左/上，1 贴右/下）。要让原图上某一点居中，用 `python3 scripts/kb.py img/x.jpg u v 缩放` 算。
- 人像、雕像：对准头部，别把头裁掉。竖幅的高大对象用「从下往上」的平移带出尺度。
- 同一张图第二次出现要换运镜、换景别。
- 视频片段默认叠一点点推近（1.00→1.04）；动画片段不叠。
- 叠化默认 0.7 秒。章节开头用 `"tr": "rack"`（焦点转移），情绪段用 `light`（暖光溶解）或 `luma`（暗部先浮现），`xf` 设 1.0 秒。**不用闪白、甩镜、猛推**。
- 片头 `fade_in`，片尾 `fade_out` 约 2 秒。

## 4. 叠层

每个镜头的 `ov` 是一组叠层，`in` 是镜头开始后几秒出现，`dur` 是停留多久（不写就到镜头结束）。

| kind | 样子 | 规则 |
|---|---|---|
| `title` | 片名大字 + 系列名 | 片头、片尾 |
| `place` | 左上角地点牌（中文 + 外文） | 到一个新地方时 |
| `chapter` | 居中奶油色章节卡 | 每章一张，配 `rack` 转场 |
| `name` | 人名牌（中文名、原名、生卒年） | 人物**首次**出现；图必须是这个人 |
| `art` | 作品牌（名称、年份、收藏地） | 每件作品 |
| `card` | 纸片卡：小标签 + 逐字出现的一句话 + 关键词下划线高亮 | 关键事实、要点 |
| `big` | 大数字 + 说明 | 数字说出口的那一刻 |
| `year` | 右上角大年份 | 关键年份 |
| `quote` | 衬线大字引文 + 出处 | 稿里引用的原话 |
| `callout` | 圆圈 + 折线 + 说明卡，`ix/iy` 钉在原图坐标上，跟着镜头运动 | 指出一个细节 |
| `tlstrip` | 顶部时间线条 | 由 `add_tlstrip.py` 按 `timeline.json` 自动挂 |

- **标签必须落在它说的那张图上。** `callout` 的 `ix/iy` 是该细节在原图上的归一化坐标——打开原图量，不要估。圈不准（比如一行铭文）就改用 `focus` 的矩形框。
- 卡片的 `in` 对准答案开始的时间，而不是镜头开始的时间。
- 标签不进字幕带（画面底部约 160 像素），有时间线条时也不进顶部条带。引擎已经避让，自定义位置时要留意。
- 全屏动画自带标题和标注，不要再压章节卡、时间线条以外的东西。

## 5. 节奏

- 9 分钟左右的片子 80–100 个镜头；每个镜头 ≥3 秒，平均 5–6 秒。
- 相邻镜头换类型：静态图连放不超过 3 个，就要插视频、聚焦、对比或动画。
- **问句处画面停住或慢推，答案落下的那一刻切镜或弹卡。** 不在问句中间切镜头。
- 关键数字：先问（画面停），数字说出来时大数字卡弹出。
- **开场 15 秒**：视频 → 标题 → 一个让人想往下看的画面（细节特写或动画）。开场 5 秒内抛出问题，并预告全片最好看的那段画面。
- 章节卡压在一段稳定的画面上（航拍环绕最合适），不要压在信息很多的图上。
- 结尾落在对象的全景上，慢慢淡出。

`python3 scripts/richness.py <ep>` 统计各类镜头和叠层的数量、最长的连续静态图。

## 6. 短镜头合并

```bash
cp shots_src.json shots.json
python3 scripts/short_shots.py . 3.0     # 列出短于 3 秒的镜头：先自己改锚点，把它们挪到相邻短句
python3 scripts/merge_short.py . 2.4     # 仍然过短的并入邻居
python3 scripts/add_tlstrip.py .         # 挂顶部时间线
```

合并有副作用，合并后对比 `shots_premerge.json` 和 `shots.json`：

- 人名牌、作品牌、标注必须还跟着自己的图。合并器会让带这类标签的短镜头接管邻居的时段，而不是把标签挪到别人的图上；但仍要核对。
- 标题镜头、章节镜头不能被吞掉。很短的开场白镜头最容易连同标题卡一起消失。
- 动画镜头不参与合并（它的时长是算好的）。

最稳妥的做法是写镜头表时就让每个镜头 ≥3 秒，合并只做兜底。

## 7. 顶部时间线

`timeline.json` 的每个事件在口播说到触发短语时点亮，进度从上一个事件滑到当前。全片同一组事件，观众随时知道讲到了哪一年。全屏动画镜头上自动跳过（会压字）；地图类动画挂在下方。

## 8. 整体结构的几个做法

- **钩子镜头**：航拍推近 + 一段预告性的动画，在固定开场白之前。
- **每章一段航拍或实景视频**打底，章节卡压在上面。
- **实拍和示意交替**：讲结构、尺度、过程时切到动画；讲细节、质感时回到实拍照片。
- **照片小窗嵌进示意图**：动画讲到某个部位时，把对应的实拍照片嵌进去，观众知道示意图说的是真东西。
- 讲完一个复杂过程后，用一张对比（`split`）或一张卡片（`card`）收一下。
